# Supporting mathematical checks

The notes in this directory record checks of the common-scale calculation, coupled inequality, numerical extensions and saved ledgers. The scale calculation is in §4.1 of [the paper](../../manuscript/report.md), and the coupled inequality is Proposition I.1 in Appendix I.

The deterministic coupled example is completed in [the separate proof and execution](../revision-round2/README.md). Coupled remainder moments for the stochastic-variance Heston points remain uncomputed. Numerical execution records are in [the evidence archive](../../code/revision/results/INDEX.md).

These notes document derivations and saved-result checks.
