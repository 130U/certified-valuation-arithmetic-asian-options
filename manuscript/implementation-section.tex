\texttt{5bc72cf6036fdd73fea9c8bc6c85f85fd474b79a}.
This revision retains those core formulas and the established exact reference
payloads. The file \texttt{REVISION-MANIFEST.json} additionally freezes new readers, experiment
inputs, and receipts. A content hash identifies bytes; it does not certify a proof.

From the repository root, create a CPython 3.12 virtual environment and install
\texttt{python-flint==0.8.0} through
\texttt{python -m pip install -r code/requirements.txt}.
The reference runtime is Windows x86-64. This repository contains no dependency
wheel; offline installation requires a separately obtained authentic compatible
wheel. After installation the numerical calculations perform no network calls.
The exact interpreter-bound commands are
\texttt{py -3.12 -m venv .venv},
\texttt{./.venv/Scripts/python.exe -m pip install -r code/requirements.txt},
\texttt{./.venv/Scripts/python.exe code/run.py verify}, and
\texttt{./.venv/Scripts/python.exe code/run.py run --module asian --independent}.
Use \texttt{--module all} for all modules. Do not use optimized Python: assertions
enforce mathematical and resource conditions.

The run prints a unique directory under \texttt{code/runs/}. Its
\texttt{run-receipt.json}, \texttt{mathematical-check.json}, per-job logs, and
\texttt{work/core/*-result.json} preserve the exact inputs, source identities,
guard outcomes, rational endpoints, and all fees. Run
\texttt{python code/run.py check --run code/runs/run-ID} using the actual ID to
recheck a completed calculation. The configuration records timeouts and module
dependencies. Workers use one thread and a 256 MiB hard memory limit. A stopped
job is not a completed certificate.

The weighted moments in (4.6) correspond to
\texttt{code/reference/asian-remainder-result.json}; the linear center, inversion,
projection, and final intervals correspond to
\texttt{code/reference/asian-linear-result.json}. The nonlinear catalog implements
Appendix A, the projected recurrence Appendix B, and linear inversion Appendix C.
Exact synthetic calibration observations are in
\texttt{code/data/synthetic\_quotes.json}. The revision's budget reader exposes
the displayed rows and their rational source fields in one machine-readable file.

The comparison retains every numerical JSON field, including arrays, fee terms,
and rational endpoints. It excludes hash metadata and six explicitly named elapsed
time fields. The implementations share Arb and the mathematical derivation;
agreement is evidence of reproducibility within those assumptions, not independent
validation of the underlying derivation. The main source, exact dependencies,
commands, result mapping, and verification scope are all available to a referee.


Revision commands, source-patch contracts, and all attempted-run records are
indexed in \texttt{code/revision/README.md}. The machine-readable budget table
is \texttt{code/revision/results/revision-summary.json}; it maps each numerical
row to its result path, exact source field, and receipt. The original completed
rerun receipt is preserved with the revision evidence. The scientific manifest
lists final sources, inputs, enclosures, and receipts by byte count and SHA-256.
The declared resource extension at the finest step changes only the bounded
wall-time allowance; the original failed attempt is retained separately.
